# AI Interview Coach

AI-powered interview preparation platform that helps users practice interviews, receive feedback, and improve their interview performance.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### AI
- AI-powered interview questions and feedback

## Features

- User registration and login
- Secure JWT authentication
- AI-generated interview questions
- Mock interview sessions
- Answer evaluation
- Interview feedback
- Interview history
